# Restaurant AI Chatbot Demo — Casa Verde Mexican Kitchen

A single self-contained `index.html` demo: a fictional restaurant homepage
("Casa Verde Mexican Kitchen", Denton, TX) with an embedded rule-based AI
chatbot widget named **Verde**.

## What it does

- **Restaurant homepage** — hero, full menu (tacos / enchiladas / fajitas /
  sides & sips with prices), about/story section, hours + location + contact,
  mobile-responsive, no external dependencies (inline CSS/JS only).
- **Chatbot widget "Verde"** — warm, friendly host personality with typing
  indicator, quick-reply chips, and keyword/intent-based responses.

## Chatbot features

- **FAQs**: hours, location + parking, vegetarian/vegan options, spice levels,
  prices/specials, menu browsing by category.
- **Table reservation flow**: collects name → phone (validated 10 digits) →
  date → time → party size → confirmation summary with reference code.
- **Catering inquiry flow**: collects name → phone → event date → guest count
  → summary; promises a callback from the catering team within 1 business day.
- **Callback/lead capture**: fallback flow that collects name + phone for a
  staff callback.

## Running it

Open `index.html` in any browser — no server or build step needed. Click the
💬 chat bubble (bottom-right) to talk to Verde.
